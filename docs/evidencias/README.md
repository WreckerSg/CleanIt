## Evidencia real requerida en el futuro

Cuando exista una versión funcional, cada ejecución debe incluir:

1. identificador del commit o etiqueta de versión;
2. fecha, ambiente y persona ejecutora;
3. caso y datos utilizados;
4. resultado observado y estado;
5. captura o salida original cuando aporte valor;
6. enlace a la incidencia en GitHub si falla;
7. evidencia de reprueba después de corregir.

Las capturas no deben mostrar contraseñas, tokens, correos reales ni otra información personal.

## Evidencia real requerida en el futuro

Cuando exista un MVP, cada ejecución deberá incluir:

1. caso y requisito relacionados;
2. commit, rama y etiqueta de versión;
3. ambiente y versiones de sus componentes;
4. fecha, hora y ejecutor;
5. datos utilizados;
6. esperado, observado y estado;
7. captura o salida original cuando aporte valor;
8. incidencia y reprueba si se detecta un defecto.

Las evidencias reales reemplazarán estas simulaciones; no se mezclarán dentro de un mismo informe.

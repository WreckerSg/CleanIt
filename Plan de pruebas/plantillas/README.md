# Plantillas del proceso de pruebas

Estas plantillas estandarizan el diseño y la futura ejecución de casos. Fueron adaptadas de la estructura académica proporcionada para requisitos funcionales y no funcionales.

- [Plantilla de caso de prueba](Plantilla_caso_de_prueba.md): se completa durante el diseño.
- [Plantilla de registro de ejecución](Plantilla_registro_de_ejecucion.md): se completa cada vez que un caso se ejecuta sobre una versión identificada.

La definición del caso y su registro de ejecución se mantienen separados: un mismo caso puede ejecutarse muchas veces en diferentes commits, ambientes o navegadores.
